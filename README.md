本仓库提供可直接运行的 Windows x64 客户端，用于搜索、监控 B 站市集商品价格。

## 下载、安装和使用

1. 下载仓库中的 `BiliMarketPriceMonitor.exe` 与 `manifest.sha256`，放在**同一目录**。也可通过 GitHub Releases 发布这两个文件，供用户从 Releases 下载。
2. Windows 10/11 安装 Microsoft Edge WebView2 Runtime（多数系统已自带），双击 EXE 启动；无需安装 Python 或 Node.js。
3. 首次运行如遇 Windows SmartScreen「未知发布者」，请先确认下载来源和校验值，再自行决定是否运行。本版本未进行 Authenticode 数字签名，SHA-256 清单不是发布者签名。
4. 默认关闭窗口会隐藏到系统托盘，继续监测；右键托盘图标选择退出，才会停止监测。

## 主要功能

- **商品搜索**：按关键词搜索 B 站市集商品，查看商品名称、当前价格及商品链接。

- **价格监控**：将需要关注的商品加入监控列表，按设定的检查周期自动查询价格变化。

- **关注列表**：集中管理正在监控的商品，可随时新增、移除或暂停关注。
- **价格历史**：在本地保存查询结果，查看商品价格的变化趋势，辅助判断入手时机。
- **降价提醒**：商品价格达到设定条件时进行提醒；提醒方式以客户端内提示为主，也支持配置 PushPlus 或企业微信群机器人通知。

- **系统托盘运行**：关闭主窗口后默认最小化到系统托盘，后台继续执行监控任务。

## 使用方法

### 1. 搜索商品

启动程序后，在搜索框中输入商品名称或关键词，执行搜索。选择目标商品后，可以查看当前价格和商品详情，并将其加入关注列表。

### 2. 添加和管理监控

在关注列表中添加商品，并根据需要设置监控参数：

1. 打开关注列表，确认商品信息和当前价格。
2. 设置检查周期或提醒条件（如果界面提供对应选项）。
3. 保存设置，保持程序运行，客户端会在后台定期检查。
4. 不再需要监控时，可暂停或删除对应条目。

> 监控依赖网络连接和 B 站接口可用性。请避免设置过短的检查周期，以免产生不必要的请求。

### 3. 查看价格历史

打开商品的价格历史，即可查看本机记录的历史查询结果。首次添加商品时没有历史数据属于正常情况；运行一段时间后才会形成可供比较的记录。

### 4. 配置通知

如需接收外部推送，在设置中填写对应服务的配置：

- **PushPlus**：填写个人 PushPlus Token。
- **企业微信机器人**：填写机器人 Webhook 地址。

请妥善保管 Token 和 Webhook，不要将包含敏感配置的截图、配置文件或日志公开上传。留空时可仅使用客户端内的提醒功能。

### 5. 退出程序

单击关闭按钮通常只会隐藏窗口，监控仍会继续。需要完全停止程序时，请右键单击系统托盘图标并选择“退出”。

## 首次运行建议

1. 先完成一次商品搜索，确认网络访问正常。
2. 添加一个商品进行测试，观察价格是否能正常刷新。
3. 如需推送，先使用一个测试商品验证 Token 或 Webhook 配置。
4. 确认程序能够正常工作后，再添加更多商品或调整监控周期。

## 常见问题

### 搜索不到商品或价格没有更新

请检查网络连接，稍后重试；也可能是 B 站接口临时不可用、商品已下架或接口返回的数据发生变化。不要在短时间内连续频繁刷新。

### 关闭窗口后为什么程序仍在运行？

这是默认的托盘模式，方便持续监控。请通过托盘菜单选择“退出”来彻底结束程序。

### 没有收到推送通知

确认 Token 或 Webhook 地址填写正确，通知服务本身可用，并检查网络、防火墙及服务端限制。建议先使用测试配置验证，再等待下一次价格条件触发。

### 数据保存在哪里？

关注列表、价格历史、设置和通知配置默认保存在本机数据库。具体位置可能因版本、运行权限或自定义路径而不同；迁移或清理数据前，建议先退出程序并备份相关数据。

```powershell
(Get-FileHash .\BiliMarketPriceMonitor.exe -Algorithm SHA256).Hash
```

## 数据与隐私

客户端在本机查询 B 站市集接口，关注列表、价格历史、设置和通知默认保存在本机数据库；旧版本或自定义路径可能不同。手机推送功能使用用户自行填写的 PushPlus Token 或企业微信群机器人 Webhook。
